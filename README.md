## ⚡ Tecnologias e Recursos
- **Tailwind CSS (v3):** Design responsivo, moderno e estilizado com a paleta oficial da empresa (Verde Esmeralda + Cinza Slate).
- **SEO Local Avançado:** Meta tags completas, OpenGraph para redes sociais/WhatsApp e dados estruturados em `JSON-LD` (`Schema.org/Dentist`).

- **Botão Flutuante do WhatsApp:** Chamada rápida permanente com efeito de pulso.
- **Accordion FAQ Interativo:** Seção de dúvidas frequentes em JavaScript limpo.
